# CABLE 研究项目

## 一句话定位

> CABLE（Cross-Architecture Boundary Learning for Effect-Guided Compiler Optimization）研究如何利用多个硬件架构上的真实编译与运行效应，学习编译优化知识的跨架构适用边界，并在通用知识失效时进行有方向的架构专用调优。

中文名称：**面向效应引导编译优化的跨架构知识边界学习框架**。

## CABLE 想解决什么

同一项优化在 x86、ARM 和 RISC-V 上可能产生不同结果。传统方法通常选择共享一套策略，或者为每个平台重新调优；前者可能发生负迁移，后者又无法沉淀可复用知识。

CABLE 希望回答三个问题：

1. 哪些编译优化知识能够跨架构稳定复用？
2. 一项通用知识在目标架构上何时已经失效？
3. 失效后应根据什么后端证据进行架构专用修正？

## 总体结构

CABLE 包含两个功能模块：

- **通用知识学习模块**：从多架构真实效应中提取、分类并维护编译知识；
- **架构专用调优模块**：依据目标架构的效应失配，调整 IR Pass、Pass 宏动作或后端配置。

两个模块由真实证据闭环连接：

```text
多架构真实测量
    -> 效应条件化知识提取
    -> 学习知识适用边界
    -> 目标架构一致性检查
    -> KEEP / REFINE / REPLACE
    -> 必要时进行架构专用调优
    -> 追加真实证据或反例
    -> 更新知识边界
```

双模块只是总体结构，不单独作为创新点。

## 三个核心创新

1. **效应条件化的跨架构编译知识分解**：将知识表示为适用条件、优化动作、预期效应、适用边界和实测证据，并识别通用稳定、架构敏感、架构冲突和架构专用知识。
2. **反例驱动的知识边界学习与效应门控**：比较预期效应和目标架构实测效应，执行 `KEEP`、`REFINE` 或 `REPLACE`，并用真实反例持续修正知识边界。
3. **失配驱动的架构专用调优**：根据运行时间、代码尺寸、spill、访存、分支和向量化等效应失配，有方向地选择修正动作，而不是只根据单一性能分数盲目搜索。

## 永久技术约束

本项目在任何阶段都**不使用世界模型**，不进行 imagined rollout、虚拟 Pass 执行、编译状态转移预测或合成硬件反馈。所有知识分类、边界更新和调优结论必须由真实编译、目标代码分析、正确性检查和真实运行测量支持。

LLM、监督学习、候选排序和强化学习可以作为实现工具，但预测结果不能替代真实编译与硬件验证。当前主线也不研究未见平台快速适应。

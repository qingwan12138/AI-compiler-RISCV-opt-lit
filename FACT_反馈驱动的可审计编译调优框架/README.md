# FACT：反馈驱动的可审计编译调优框架

本目录保存 FACT 的研究设计和实验材料。FACT 全称为 **Feedback-guided Auditable Compiler Tuning**，自由组合以下三个创新点：

1. **01 Pass 因果归因**：通过删除、替换和交换 Pass 的反事实实验，识别真正产生收益的步骤；
2. **02 意图落地审计**：检查 LLM 声称的优化是否在 LLVM IR、机器码和运行结果中真实发生；
3. **05 硬件性能反例校准**：用真实硬件上的负优化反例修正候选选择和目标相关判断。

方案不围绕 RISC-V 单独展开。x86-64 用于大规模开发和主实验，进迭时空 K3 的 X100 通用核用于必须完成的 RISC-V 跨架构验证；如果其他开发板条件成熟，再增加第二个 RISC-V 平台作为外部有效性实验。

## 当前研究目标

在 6–8 个月内形成一篇面向 CCF B 类会议的系统型论文，回答：

> 一个编译优化智能体能否不仅找到更快的 Pass 策略，还能证明自己的优化意图确实落地、解释收益来自哪一步，并利用跨硬件性能反例降低负优化？

## 当前阶段

当前处于“研究设计待用户复核”阶段。此目录暂不包含实验代码、原始数据和结果；研究设计确认后，再生成具体实现计划和工程目录。

## 明确不做

- 不把 RISC-V 写成方法成立的唯一场景；
- 不在首篇论文中承诺自动生成可直接上游 LLVM 的源码补丁；
- 不把 QEMU 指令计数当作真实性能；
- 不同时覆盖源码重写、IR 重写、Pass 排序和 intrinsic 翻译四种任务；
- 不以“多智能体数量”或“使用 LLM”本身作为创新。

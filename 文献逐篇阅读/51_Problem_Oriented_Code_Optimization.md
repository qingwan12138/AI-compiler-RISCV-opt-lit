## 1. 研究问题与动机

同一程序员的局部修改对是否限制 LLM 学到全局算法级优化。

## 2. 方法与系统结构

按同一问题汇聚多程序员快慢解形成训练对，并用慢但正确程序生成锚点测试，迭代验证优化代码。

## 3. 实验与主要发现

问题导向数据将优化率从 31.24% 提至 58.90%、速度从 2.95× 提至 5.22×；锚点验证进一步到 71.06%、6.08×。

## 4. 局限与批判性阅读

竞赛程序与生成测试不能代表生产环境；结果主要是算法/API 层，不是 LLVM Pass 或跨 ISA 后端。

## 5. 对当前研究方向的关系

为 CABLE 提供“多来源反例与锚点验证”启发，但研究对象层级不同。

## 6. 可提炼的研究启发

优化数据应按问题语义而非提交轨迹组织，正确性与性能也必须分开验证。

## 7. 一句话总结

优化数据应按问题语义而非提交轨迹组织，正确性与性能也必须分开验证。

## 4. 发表状态与证据边界

- C33、C34、C35、C36、C38、C41 当前按 arXiv 预印本记录，不推断正式录用。
- C37 是 C4ML@CGO 2026 Workshop，不写成 CGO 主会论文。
- C39 的首次公开年份为 2025；COLM 2026 官方录用状态与本次阅读的 arXiv v4 分开记录。
- C41 用于说明 LLM 处理 LLVM Issue 的能力边界，不把 Issue 修复结果写成编译性能提升。
- 各笔记明确区分测试通过、形式验证、静态指标和真实性能，跨论文的 speedup 不能脱离不同 baseline 直接排序。

### 检索去重与排除说明

- ECCO、HINTPILOT、ReasoningCompiler、LLM-VeriOpt 等近期工作已在原索引中，未重复建立新条目。
- 只有“AI 编译器”关键词但不实际使用 LLM 的工作，不因时间新而强行纳入本批次。
- 标题相似但任务不同的论文仍分别保留，例如 Compiler Issue 修复、Pass 调优、图 Pass 生成和汇编超级优化；它们不能仅按“LLM + compiler”合并。
- 截止日期为 2026-09-05 的检索快照；后续出现的新版本或正式录用状态应增量更新，不把本轮列表描述为完整全集。

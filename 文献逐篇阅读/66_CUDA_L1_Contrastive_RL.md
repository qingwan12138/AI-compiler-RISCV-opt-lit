## 1. 研究问题与动机

能否仅用真实速度奖励把通用模型训练成 GPU kernel 优化器。

## 2. 方法与系统结构

在 KernelBench 上采用对比 RL，根据正确性和 A100 实测速率优化 CUDA 候选。

## 3. 实验与主要发现

250 个 kernel 平均/中位加速 3.12×/1.42×，峰值 120×；迁移到 H100、L40、3090、H20 仍有正平均收益。

## 4. 局限与批判性阅读

训练与选择偏向 A100，均值受极端值影响；跨 GPU 正平均值不等于逐程序无负迁移。

## 5. 对当前研究方向的关系

是 CABLE 的强硬件反馈基线，尤其适合比较跨平台负迁移率和知识边界。

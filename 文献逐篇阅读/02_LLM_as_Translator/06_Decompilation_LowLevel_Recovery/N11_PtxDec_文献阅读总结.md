# PtxDec 文献阅读总结

论文题目：**Enhancing LLM to Decompile Optimized PTX to Readable CUDA for Tensor Programs**

作者：Xinyu Sun、Fugen Tang、Yu Zhang、Han Shen、Chengru Song、Di Zhang

发表时间：2025

发表平台：ASE 2025

关键词：PTX 反编译、CUDA、深度学习编译器、数据增强、Rolled-PTX

> 本文档基于 PDF 全文整理。

## 1. 研究背景

深度学习编译器会生成高度优化但难读的 PTX。把它还原成可读 CUDA 有助于调试和性能分析，但公开的 CUDA–PTX 对齐数据稀缺，而且循环展开使 PTX 结构冗长、语义分散。

## 2. 论文要解决的问题

如何构建足够大且保留调度多样性的训练集，并把展开后的低层 PTX 转成更适合 LLM 理解的表示，从而生成可编译、正确、可读且尽量保留原调度的 CUDA。

## 3. 核心方法概述

PtxDec 用 Ansor 产生调度多样性、Welder 产生子图多样性，再经 TVM/CUDA 编译获得 40 万对 CUDA–PTX。CUDA 端做括号简化、索引公共子表达式提取与去重；PTX 端用启发式循环重卷形成 Rolled-PTX，最后监督微调代码模型。

## 4. 实验框架与训练流程

```text
DNN 模型 → Ansor/Welder 多样化 → CUDA → PTX
       → CUDA 重构/去重 + PTX 循环重卷
       → Rolled-PTX/CUDA 对监督微调
       → 生成 CUDA → 编译/运行/I-O/调度评测
```

## 5. 奖励函数、损失函数或关键公式

采用标准监督微调交叉熵，无强化学习奖励。I/O 正确性以输出误差阈值 0.001 判定；调度一致性比较反编译代码与原 CUDA 的延迟和全局内存加载效率偏差。

## 6. 实验设置

### 6.1 数据集来源

40 万对 CUDA–PTX kernel，随机抽取 4,000 例测试，其余用于训练；覆盖视觉、NLP、推荐模型，以及不同 batch、shape、FP32/FP16 和调度。

### 6.2 模型与工具

Qwen2.5-Coder-7B、Qwen3-32B，经 LoRA+SFT；Ansor、Welder、TVM、CUDA 编译器。训练 batch 4×8192 tokens、初始学习率 5e-5，使用 8 张 NVIDIA H20；推理 temperature=0。

### 6.3 对比方法

GPT-4o、DeepSeek-V3、未微调的 Qwen2.5-Coder-7B、Qwen3-32B，并对数据量、CUDA 重构、Rolled-PTX 做消融。

### 6.4 评价指标

编译率、运行正确率、I/O 正确率、CodeBLEU、延迟偏差和全局内存加载效率偏差。

## 7. 实验结果与结论

PtxDec-7B/32B 的编译率为 97.24%/98.15%，运行正确率 96.40%/97.24%，I/O 正确率 90.89%/91.45%。未微调 Qwen2.5-Coder-7B 的三项为 42.16%/34.61%/29.26%，GPT-4o 为 31.35%/19.23%/13.23%。PtxDec 的功能准确率相对 7B 基座提高 2.3–3.1 倍，CodeBLEU 也显著提高；延迟和内存访问偏差更集中于零附近。

## 8. 主要创新点

### 8.1 编译器驱动的大规模对齐数据

利用调度搜索和子图划分自动获得既正确又多样的训练对。

### 8.2 Rolled-PTX 中间表示

先用编译技术恢复循环结构，再交给 LLM，降低低层表示难度。

### 8.3 同时评价语义、可读性与调度

不仅看能否运行，还检查是否保留原优化策略。

## 9. 局限性

任务仅覆盖编译器生成的张量 kernel，不代表任意手写 PTX；循环重卷依赖启发式模式；I/O 测试不是形式等价证明。训练需要 40 万样本和 8×H20，成本较高，且目标只限 NVIDIA PTX/CUDA。

## 10. 阅读后的研究方向反思

本论文表明，面向低层代码时“先恢复结构，再让 LLM 推理”比单纯扩大模型更有效。迁移到跨 ISA 研究时，核心应是设计规范化中间表示，而非逐指令翻译。

## 11. 可进一步尝试的研究方向

### 11.1 PTX/RVV 到统一张量 IR 的结构恢复

#### 研究问题

不同 ISA 的优化 kernel 能否恢复到同一规范化 IR，便于迁移和比较。

#### 与原论文的区别

从 PTX→CUDA 单向反编译扩展到多 ISA→统一 IR。

#### 可能的创新点

结构重建置信度与跨架构差分验证。

#### 实验框架

```text
PTX/RVV → 循环/访存结构恢复 → LLM 生成 MLIR → 编译回各后端 → 差分测试
```

#### 可行性与风险

可从规则明确的算子开始；风险是不同后端调度语义不完全同构。

## 12. 与其他已读文献的关系

与 N09 DecLLM 都研究反编译，但 PtxDec 使用大规模监督训练并面向 GPU kernel；与 N24 BRIDGE 的共同点是先恢复规范结构再生成高层表示。

## 13. 一页式总结

| 项目 | 内容 |

| 论文研究任务 | 优化 PTX 到可读 CUDA 反编译 |
| 核心问题 | 数据稀缺、展开 PTX 结构复杂 |
| 输入/输出 | Rolled-PTX / CUDA kernel |
| 核心方法 | 编译器数据增强 + Rolled-PTX + SFT |
| 使用的模型 | Qwen2.5-Coder-7B、Qwen3-32B |
| 使用的编译器工具 | Ansor、Welder、TVM、CUDA |
| 是否使用强化学习 | 否 |
| 是否使用形式化验证 | 否 |
| 数据集规模 | 400K 对；测试 4K |
| 主要指标 | 编译/运行/I-O、CodeBLEU、调度偏差 |
| 最重要实验结果 | PtxDec-32B I/O 正确率 91.45% |
| 核心创新 | 结构重卷与编译器驱动数据构造 |
| 主要局限 | 仅张量 PTX，测试不等于证明 |

> 最关键的启示是先用编译器恢复可学习结构；不能把高 I/O 通过率理解为任意输入都等价。

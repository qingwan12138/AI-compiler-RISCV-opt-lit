# 语料库重构建议：面向文献综述写作

## 1. 先说结论

当前库不需要推倒重建。六类文件夹适合存放 PDF 和阅读笔记，应继续作为**物理归档层**；真正需要新增的是一层**写作视图**，把论文从“按目录找到”变成“按论点调用”。

当前 169 个索引条目中，2024–2026 年占 130 条（76.9%）。用户感受到“文献偏老”，一部分来自 36 条较早文献，另一部分来自以下结构问题：

1. 第二类有 71 条，混有 Pass/IR 优化、源码重写、反编译、代码生成、RTL 和通用 Agent，写综述时难以形成清晰叙事。
2. 年份、首次公开年份、正式录用年份和本次阅读版本没有统一拆开。
3. “高优先级”不能直接说明论文在某段 Related Work 中承担什么角色。
4. 阅读笔记重在逐篇完整，缺少可直接组成段落的“主张—证据—限制”视图。
5. 关系如果只显示 `PAPER-xx / METHOD-xx` 编号，对写作者并不直观。

## 2. 推荐结构：一份原始库，四种写作视图

```text
物理归档层（保留现状）
六类目录中的 PDF + 13 节阅读笔记
             │
             ▼
唯一元数据层
标题 / 作者 / DOI或arXiv / 首发年份 / 正式状态 / 阅读版本
             │
      ┌──────┼──────────┬──────────┐
      ▼      ▼          ▼          ▼
时间视图  主题视图   证据视图   写作大纲视图
```

建议新增一个 `写作视图/` 目录，但第一阶段先建立模板与规则，不搬动现有文件：

```text
写作视图/
├── 00_近三年前沿导航.md
├── 01_主题比较矩阵.md
├── 02_论点与证据台账.md
├── 03_Related_Work段落地图.md
└── 04_经典基线与历史脉络.md
```

## 3. 近三年前沿导航

作用：打开一个文件就能看到 2024–2026 的主线，而不是在 169 条记录里寻找。

导航不再复制六类目录，而按写作问题组织：

| 写作主线 | 需要比较的对象 |
|---|---|
| 优化决策与搜索 | Pass 选择、Phase Ordering、Agent 搜索、RL、MCTS |
| 程序与 IR 变换 | 源码、LLVM IR、MLIR、汇编、图 Pass 生成 |
| 规则与启发式生成 | peephole、InstCombine、编译器 heuristic、超级优化 |
| 正确性保障 | 编译、测试、Alive2/SMT、运行时验证、受约束生成 |
| 性能反馈与代价 | 静态代理指标、代价模型、runtime、硬件计数器、测量成本 |
| 基准与能力边界 | 数据集、benchmark、IR 理解、失败模式、外部有效性 |

每篇论文只选一个“主要写作位置”，再用最多三个标签表达交叉主题。RISC-V、GPU、x86、ARM、NPU 等作为平台标签，不必再次改变物理分类。

## 4. 主题比较矩阵

矩阵应围绕论文写作最常见的比较句，而不是罗列所有技术细节：

| 文献 | 任务 | 输入 | 输出动作 | 反馈 | 正确性 | 主性能指标 | 强基线 | 适用范围 | 关键限制 |
|---|---|---|---|---|---|---|---|---|---|

字段规范：

- `反馈` 与 `正确性` 分开：编译成功不是语义等价，测试通过也不是形式证明。
- `主性能指标` 标出静态或动态；没有 runtime 就写“未报告”，不推断无效。
- `强基线` 写明 `-O3`、传统 autotuner、SOTA LLM 或人工专家，而不是只写“有”。
- `适用范围` 写源语言、IR、硬件和 benchmark，避免把局部结论泛化为通用结论。
- `关键限制` 只记录论文正文、实验或可核验设置支持的边界；研究者推断另行标记。

矩阵只收核心论文和必要传统基线，建议 30–50 篇，不把全部 169 条塞入。

## 5. 论点与证据台账

这是最能直接帮助写综述的部分。每条记录不是“某论文讲了什么”，而是“我能据此写出什么有边界的句子”。

| 论点 ID | 可写论点 | 支持文献 | 反例/限制 | 证据位置 | 证据等级 |
|---|---|---|---|---|---|
| CLM-001 | LLM 已被用于受控优化空间的决策搜索 | 论文题名 + ID | 任务与平台边界 | 页码/表格 | 直接实验 |

证据位置至少记录页码、表格或章节。证据等级建议使用可读词语，而非只用数字：

- `直接实验`：表格、消融、失败案例或真实运行结果；
- `正文陈述`：作者明确说明，但没有独立实验；
- `写作者推断`：由多篇论文组合得出，不能冒充作者结论。

不要为每条证据创建独立 Markdown 文件；集中表格或结构化数据更适合检索与校验。

## 6. Related Work 段落地图

一篇论文不应只分“核心/非核心”，还要标明写作用途：

| 写作角色 | 含义 |
|---|---|
| 奠基/基础设施 | 定义问题、IR、验证器或 benchmark |
| 同任务竞品 | 解决同一问题，可作直接比较 |
| 方法来源 | 提供 RL、Agent、验证、代价模型等机制 |
| 证据或反例 | 支撑能力边界、失败模式或评价缺陷 |
| 最新前沿 | 2026 新路线或重要状态变化 |
| 一般背景 | 只需在引言或背景简述 |

段落地图可按以下骨架生成：

```text
段落主题
→ 该主题的传统起点
→ 2024–2026 的主要方法分支
→ 各分支的共同证据与差异
→ 尚未解决的边界（只写文献证据，不展开研究方案）
```

这样，旧论文只有在承担“奠基/基线”角色时进入正文；其余旧论文保留在总库但不会挤占写作视野。

## 7. 更直观的关系表达

不建议把整张关系网首先展示为编号表。写作者默认看到的是论文简称与一句关系理由：

```text
AutoPhase
  └─ 为 CompilerGym/后续 RL Pass 搜索提供早期任务范式

Compiler-R1 ── 全局 Pass 搜索
LLM-VeriOpt ── 局部 IR 变换与验证
  └─ 写作者推断：二者在搜索粒度和正确性机制上互补
```

底层仍可保留 ID，但可视层必须同时显示：

- 论文简称或短标题；
- 关系动词；
- 一句话证据或理由；
- `论文事实` / `写作者推断` 标记。

只为影响写作叙事的核心论文建立关系；孤立论文不等于低价值，也不强迫每篇论文连边。

## 8. 唯一数据源与版本字段

总索引应逐步增加以下规范字段，避免同一事实维护多份：

```yaml
paper_id: C39
canonical_title: SuperCoder: ...
first_public_year: 2025
formal_venue: COLM 2026
formal_status: accepted
doi: null
arxiv_id: 2505.11480
read_version: v4
note_status: full_pdf_read
note_model: gpt-5.6-luna
```

建议的权威位置：

| 信息 | 唯一权威位置 |
|---|---|
| 标题、作者、稳定标识、发表状态、版本 | 元数据清单 |
| 全文分析 | 逐篇阅读笔记 |
| 横向差异 | 主题比较矩阵 |
| 可引用论点与证据位置 | 证据台账 |
| 段落安排 | Related Work 段落地图 |

其他文件只引用 Paper ID 和标题，不重复维护完整元数据。

## 9. 旧文献处理

不删除，改成写作分层：

1. `前沿主线`：2024–2026 且直接服务于 LLM + 编译优化；
2. `经典基线`：较早但仍被近年论文使用，或定义了关键工具/问题；
3. `背景归档`：相关但不参与当前论证；
4. `待核验`：年份、渠道、全文或身份尚不可靠。

默认写作入口只显示前两层。年份不是论文价值的一票否决条件，但较早论文必须说明保留角色。

## 10. 推荐实施顺序

### 第一阶段：元数据清洗

- 合并已知重复版本的逻辑身份，但暂不删除或重编号旧文件；
- 分离首次公开年份、正式发表年份和阅读版本；
- 核验“待确认”的会议、年份和材料类型；
- 为所有条目标注写作层级与写作角色。

### 第二阶段：建立写作视图

- 先从 30–50 篇核心与基线文献生成主题比较矩阵；
- 为每个主题形成 3–8 条有证据位置的可写论点；
- 形成 Related Work 段落地图；
- 近三年前沿导航由元数据自动汇总，避免手工重复统计。

### 第三阶段：关系与质量校验

- 只画 4–6 张局部技术路线图，不画 169 节点总图；
- 默认隐藏纯编号和低置信推断；
- 检查每个段落是否同时有近期工作、必要经典基线和限制证据；
- 检查引用句是否超出原论文实验范围。

## 11. 本轮不做的重构

- 不移动六类 PDF 和既有阅读笔记；
- 不删除旧论文；
- 不修改研究方案、候选课题或实验计划；
- 不把 Method Card、Evidence Card 拆成大量单独文件；
- 不用评分自动替代对论文角色和证据质量的判断。

## 12. 验收标准

重构真正有效，应当让写作者在不重新搜索整库的情况下回答：

1. 2024–2026 年某条主线有哪些代表论文？
2. 这些论文在输入、输出、反馈、正确性和真实性能上有何差异？
3. 某个综述论点由哪些直接证据支持，证据在哪一页？
4. 哪些结论只是写作者推断，哪些是论文事实？
5. 每篇旧论文为什么仍值得出现在正文或参考文献中？

这比继续增加新的分类或 Card 类型更能直接提高文献综述的可写性和可信度。

## 1. 研究问题与动机

能否训练一个小型通用纠错器修复不同 LLM 的翻译错误。

## 2. 方法与系统结构

从 C++、Java、Python 翻译失败中学习编译、运行、功能和不终止四类错误，并跨模型应用。

## 3. 实验与主要发现

实验表明纠错器能提升多种 LLM 与语言对的翻译成功率，交叉实验支持一定鲁棒性。

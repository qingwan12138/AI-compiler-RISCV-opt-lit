# MAPO-Pass 研究路线图

> 原则：每一阶段只回答已具备证据条件的问题；缺少真实平台时不提前作性能结论。

## 1. 阶段总览

| 阶段 | 目标 | 必要资源 | 通过门 | 允许的结论 |
|---|---|---|---|---|
| R0：材料与环境 | 固定主张、工具链、基准来源 | WSL2、LLVM、交叉工具链 | 文档、版本和来源可追溯 | 研究与实验可启动 |
| P0：无设备管线 | 候选生成、三目标编译、正确性、结果格式 | x86 主机 + QEMU | 6–8 程序、16–32 候选、完整失败记录 | 管线可运行，不含性能主张 |
| P1：模拟筛选（可选） | 调试候选和模型接口 | gem5 或明确模拟器配置 | 标明配置和模拟限制 | 模拟机制可行 |
| P2：真实平台差异 | 验证 H0 | 至少两台真实设备，优先三类 | 排名/Top-k/regret 与预注册阈值 | 是否需要平台适配 |
| P3：留一平台适配 | 验证 H1/H2 | 三类真实平台 + 固定预算 | 等预算基线、bootstrap CI、风险指标 | 响应指纹与少样本适配价值 |
| P4：反事实辅助 | 解释关键 Pass 边际效应 | P3 主结果已冻结 | 有限删除/交换与 IR/汇编证据 | 解释，不改变主结果 |

## 2. 当前状态（2026-07-18）

已完成 R0 的主要环境部分，并完成 P0 的三目标基线冒烟：LLVM 18、RISC-V 交叉工具链、AArch64 交叉工具链和 QEMU 用户态模拟器均可用；官方 LLVM test-suite 的 PolyBench/TSVC 已固定到提交 `3396731658fc485536a2aa690b5eff7b3087df0b`。

`correlation` 已在 x86_64、AArch64/QEMU、RISC-V/QEMU 以官方浮点约束编译并得到完全相同的输出哈希。该结果仅证明交叉编译与功能一致性，不是 AArch64/RISC-V 性能结论。P0 尚未达到验收：候选 Pass 自动化、6–8 程序覆盖、5 个边界输入 + 20 个固定种子输入、结构化 run 记录尚待完成。

## 3. P0 的执行顺序

1. 冻结 `benchmarks/` 源码、许可和子集 manifest；
2. 注册 6–8 个程序、输入族和浮点比较规则；
3. 注册 16–32 条候选及其生成种子；
4. 为 `x86_64`、`aarch64`、`riscv64` 执行候选编译；
5. 对本机/QEMU 输出做参考比对；
6. 记录成功、编译失败、崩溃、超时和不一致；
7. 生成 run manifest、候选明细、汇总和可复现命令；
8. 审查所有记录后再宣布 P0 通过。

P0 不训练收益模型、不输出跨目标速度比较、不以 QEMU 运行时间排序候选。

## 4. 从 P0 到 P2 的资源门

P2 前至少确认：真实平台可登录和反复执行、每个平台可独立获得 CPU/OS/编译器元数据、可控制或记录线程和频率策略、可执行预热和 7 次重复、可保存原始时间。建议的最小组合为两台不同微架构 x86 加一台真实 RISC-V；若只有两台，结论应限制为“观察到两平台差异”，不可写成未见平台泛化。

## 5. P2 的预注册决策门

在任何模型训练前固定候选池、程序族划分、随机执行顺序和以下继续条件。满足至少两项才进入 P3：Spearman 中位数 $\le0.80$ 且 CI 上界 $<0.90$；Top-5 重合率中位数 $\le60\%$；跨平台迁移 regret 中位数 $>1\%$ 且 CI 下界 $>0$；至少四个程序出现收益方向翻转；平台专属最优相对公共候选的宏几何平均收益 $>1\%$ 且 CI 下界 $>0$。

## 6. P3 的固定预算与结论门

每个留出平台的总预算先设为 80 个真实测量单元：16 个指纹任务和 64 个程序—候选校准对。所有基线拥有相同总预算；不使用指纹的基线得到等量预注册的程序—候选观测。三次留一平台的宏平均中，MAPO-Pass 对“共享—残差 + 静态规格”至少有 1% 几何平均收益优势且程序族 bootstrap 95% CI 下界为正，才能支持 H1；对普通共享模型满足相同门槛且风险不过线，才能支持 H2。

## 7. 风险与降级

| 风险 | 处理 |
|---|---|
| P0 大量候选不可编译或不正确 | 缩小到稳定动作白名单，保留失败记录并更新候选版本 |
| P2 排名几乎一致 | 增加平台敏感工作负载和候选，不增大模型 |
| H1/H2 不成立 | 收缩为数据集、管线或响应可行性结果，不声称优势 |
| 测量噪声过高 | 复查环境、扩大工作负载/重复，不选择性删异常值 |
| 缺少第三真实平台 | 停在跨平台差异研究，不主张未见平台少样本泛化 |

# 反事实 Pass 信用的辅助证据

> 定位：解释与辅助监督模块，不是 MAPO-Pass 的主结论来源。

## 1. 问题

候选序列整体收益不能直接推出某个 Pass 的因果贡献。为获得可审阅的边际证据，对冻结的代表性候选执行有限反事实：删除关键 Pass、与相邻 Pass 交换，并在相同平台和相同正确性/计时协议下重新测量。

对于序列 $S$ 中第 $i$ 个 Pass，删除边际效应记为：

$$C_i(p,h)=\log\frac{T(S^{-i},p,h)}{T(S,p,h)}.$$

## 2. 执行边界

- P4 仅在 P3 主结果冻结后执行；
- 每平台建议 3 个程序、每程序 3 个关键 Pass；
- 保存原序列、反事实序列、IR diff、汇编变化、正确性、运行时间与失败原因；
- 目标平台反事实测量不计入 P3 的 80 单元主预算，不得反向更新主模型。

训练阶段若使用信用辅助损失，其标签和权重只能来自源平台训练数据。必须与“不使用信用辅助损失”的模型比较。

## 3. 可报告与不可报告的结论

可报告：某 Pass 在给定程序、序列和平台上的条件边际效应；信用信号是否提升排序解释或辅助训练。不可报告：单个删除实验给出对所有程序、所有顺序和所有平台的一般因果结论。

若信用不带来稳定排序增益，应将其保留为解释性材料，不将其拆分为独立论文贡献。

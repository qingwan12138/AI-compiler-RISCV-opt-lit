# 信息价值门控框架：预实验 Demo

## 1. Demo 目标

用最小成本回答两个问题：

1. 不同反馈是否真的会让 LLM 选择不同动作？
2. 基于这种变化选择反馈，能否比固定阶段规则在相同预算下得到更多有效优化？

## 2. 规模

- 20 个 C 函数；
- 4 类反馈；
- 5 种反馈策略；
- 每任务最多 3 轮；
- 每方法每任务最多 3 个候选；
- 一个固定 LLM；
- 不训练大模型。

## 3. 第一部分：离线反事实表

从 20 个任务中采集约 40 个代表状态。每个状态分别提供：

- 无新增反馈；
- 编译诊断；
- 测试差异；
- optimization remark；
- IR 统计。

记录下一动作和候选。人工规则只判断动作是否实质改变，不评价自然语言是否更好听。

## 4. 第二部分：简单门控器

首版特征：

- 当前阶段；
- 已观察反馈类型；
- 剩余预算；
- 当前候选是否编译/测试通过；
- LLM 下一动作置信差；
- 反馈预计 Token 和工具时间。

使用简单规则或逻辑回归估计 `P(change)`。门控器只在开发状态拟合，在剩余任务上测试。

## 5. 第三部分：在线策略对比

比较：

1. 全量反馈；
2. 随机单反馈；
3. 固定阶段规则；
4. VOI 门控；
5. VOI 门控但不能停止。

所有方法使用相同 Token、最多 3 轮、最多 3 次编译和测试。

## 6. 最低记录项

- 每轮可选反馈；
- 每条反馈预计成本；
- 选择结果与原因；
- 选择前后动作；
- 是否发生实质决策变化；
- 候选是否编译、测试和静态改善；
- 剩余预算和停止原因。

## 7. 成功标准

- 至少一种反馈的决策变化率明显高于其他反馈；
- 决策变化不是纯措辞变化；
- VOI 在等预算下不弱于 StageRule，并显示更低成本趋势；
- 允许停止比禁止停止减少无效轮次；
- 有效优化不是由错误代码产生。

若 VOI 只优于全量反馈，却不优于 StageRule，则暂不扩大实验。

## 8. 预计时间

- 工具准备和任务筛选：1 天；
- 离线反事实状态采集：1—2 天；
- 简单门控和在线对比：1—2 天；
- 分析：1 天。

总计约 4—6 个工作日，主要成本是 LLM 调用而非真实性能测量。

## 9. 降级方案

- 若四类反馈生成困难：先用编译诊断、测试差异和 IR 统计三类；
- 若 LLM 无置信度：使用多个采样动作的一致率表示不确定性；
- 若工具时间差异小：仍记录 Token 和调用次数；
- 若所有反馈都不改变决策：该主线不成立，转向结构化编辑保底框架；
- 若静态指标不可靠：只作为筛选，增加少量 Top-1 计时。

## 10. Demo 结论模板

> 在 20 个函数和每任务 3 轮预算下，四类反馈的真实决策变化率分别为……。VOI 门控相对固定阶段规则的 Valid Improvement@Budget 为……，Token、工具调用和墙钟变化为……。结果是否达到扩大实验门槛：是/否。尚未验证的内容包括……。

## 11. 三创新点分阶段预实验

统一设置：20 个 C/C++ 函数、一个固定 LLM、固定 LLVM/Clang、每任务最多 3—5 轮。对同一状态生成编译诊断、测试差异、optimization remark 和 IR 统计并缓存，所有在线策略复用缓存，避免工具开销不公平。

### 11.1 阶段一：验证支撑创新一的反事实标签

1. 让 LLM 在无新增反馈时给出动作 action_without_feedback；
2. 分别加入四类反馈，记录 action_with_feedback；
3. 按动作类型、修改位置和候选排序判断 change；
4. 执行改变后的候选，用编译、测试和收益标注 beneficial_change；
5. 比较模型自报告、阶段启发式和反事实标签的 Brier Score、AUROC 与 Average Precision。

成功标准：反事实标签至少在一个主要校准或排序指标上稳定优于两个基线，并能预测有效优化。

### 11.2 阶段二：验证核心创新的在线门控

1. 用阶段一数据拟合规则、小型分类器或固定 LLM 评分器，不训练大模型；
2. 比较无反馈、全量反馈、随机反馈、固定阶段规则和完整价值门控；
3. 固定 Token、工具调用和墙钟总预算；
4. 报告 Valid Improvement@Budget、单位成本有效优化数和质量—成本曲线。

成功标准：完整价值门控优于固定阶段规则；去掉决策变化项、收益项或成本项至少有一项显著退化。

### 11.3 阶段三：验证支撑创新二的主动停止

1. 比较固定轮数、随机停止、仅 Token 预算和三维预算主动停止；
2. 每次停止后离线检查是否仍存在正价值反馈；
3. 记录 stop_reason、无效尾部轮数和停止后遗憾；
4. 对每种策略最终 Top-1 做少量运行时间复核。

成功标准：三维主动停止减少至少一种成本和无效尾部轮数，同时有效优化率没有明显下降。

### 11.4 三阶段最终输出

- 反事实反馈标签与校准表；
- 核心价值模型和三项去项消融结果；
- 四种停止策略的质量—成本曲线；
- 每轮状态、反馈、动作、预算和停止原因；
- 三项创新分别继续、降级或放弃的判断。

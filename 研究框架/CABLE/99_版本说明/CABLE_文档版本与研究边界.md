- 中文名称：面向效应引导编译优化的跨架构知识边界学习框架
- 文档版本：2026-07-14-v1
- 文档性质：研究设计稿
- 学术状态：候选创新，尚需针对性和系统性查新，不声称首次

## 2. 当前研究范围

### 纳入范围

- LLVM IR Pass、Pass 宏动作和可控编译配置；
- x86、ARM、RISC-V 等不同硬件架构；
- 真实编译、目标汇编或 Machine IR 分析；
- 真实运行时间、代码尺寸和可获得的硬件计数器；
- 跨架构通用知识提取与分类；
- 知识适用边界学习；
- 架构冲突检测；
- 面向指定架构的编译调优；
- LLM 辅助知识抽取、候选生成和诊断解释。

### 当前排除范围

- 未见平台快速适应作为论文主线；
- 世界模型、性能世界模型或编译状态世界模型；
- imagined rollout 和虚拟 Pass 执行；
- 使用预测状态转移代替真实编译；
- 使用合成运行时间或合成硬件事件作为实验结论；
- 同时建设 Compiler Memory、技能库和元强化学习系统；
- 大规模修改 LLVM 后端源码；
- 将代码翻译作为第一阶段的主要实验对象。

## 3. 永久约束

任何阶段均不使用世界模型。允许预测模型对已经真实生成的候选进行排序，但必须满足：

1. 候选实际效应由真实编译与测量确认；
2. 预测值不得写入真实性能字段；
3. 缺失测量必须标记为 unavailable 或 missing；
4. 不得将模拟数据与实机数据混合后共同支持核心结论；
5. 所有错误程序、编译失败和目标非法均作为失败样本记录。

## 4. 核心术语

### 编译知识 Knowledge

一条带适用条件、优化动作、预期效应、适用边界和实测证据的结构化规则。固定 Pass 序列只是动作的一种表示，不等于完整知识。

### 效应 Effect

优化后相对同平台基线发生的可测变化，包括运行时间、代码尺寸、机器指令、spill/reload、访存、分支和向量化等维度。

### 知识边界 Boundary

一条知识能够保持预期效应的程序条件与硬件条件集合。边界由真实正例和反例共同确定，而不是由 ISA 标签人工指定。

### 反例 Counterexample

满足知识当前适用条件、但在目标平台上出现方向相反效应、严重约束违例或无法实现预期效应的真实测量样本。

### 效应门控 Gate

依据预期效应、观测效应和证据置信度，在 `KEEP`、`REFINE` 与 `REPLACE` 中选择处理方式的决策机制。

### 失配 Mismatch

预期效应与观测效应在各维度上的偏差，用于定位通用知识在目标架构上失败的具体表现。

### 架构专用调优 Architecture-Specific Tuning

针对已识别的效应失配，对 IR Pass、宏动作或后端配置进行有限候选修正，并由真实测量选择结果。

## 5. RISC-V 的定位

RISC-V 是必须包含的重点实验平台之一，用于验证：

- 通用知识在较新后端上的适用性；
- x86/ARM 上有效的优化是否在 RISC-V 上发生冲突；
- RVV、压缩指令、寄存器压力和后端成熟度如何影响知识边界。

方法本身不限定 RISC-V，不能把“在 RISC-V 上运行”单独写成创新。

## 6. 未来扩展条件

只有在三个核心机制完成并通过基线实验后，才考虑：

- 将代码翻译候选纳入同一知识对象；
- 引入 LLM 进行更复杂的候选规划；
- 使用强化学习处理连续多步调优；
- 增加新平台适应实验；
- 扩展能耗等多目标约束。

上述扩展仍不得引入世界模型。

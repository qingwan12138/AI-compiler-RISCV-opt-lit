# 失败边界记忆驱动的反重复 LLM 编译优化器：材料索引

## 1. 框架定位

本方向研究如何把失败轨迹转成带适用条件、反例条件和失效规则的负证据，减少 LLM 在相似程序上重复提出已经失败的优化，同时控制错误拦截。

定位：**独立备选或信息价值反馈主线的第二阶段扩展。**

## 2. 文件说明

| 文件 | 用途 |
|---|---|
| `01_主线研究框架.md` | 失败边界卡片、适用门控、反例失效和研究问题 |
| `02_文献依据与创新边界.md` | RAG、历史模式、拒绝策略和经验记忆近邻分析 |
| `03_完整实验框架.md` | 跨程序家族切分、四种记忆基线、误拦截和统计 |
| `04_预实验Demo.md` | 20 个函数和人工审核卡片即可开展的 Demo |
| `05_数据记录与评价模板.md` | 卡片字段、命中、拦截、误拦截和失效记录 |

## 3. 第一阶段成功标准

- 重复失败率低于无记忆和成功案例 RAG；
- 固定预算下有效优化率不下降；
- 带边界记忆的误拦截率低于无条件失败黑名单；
- 反例出现时卡片能失效并恢复被拦截动作；
- 结果在未见程序家族中仍有方向一致性。

## 4. 核心边界

数据库、RAG、保存失败日志和拒绝当前错误策略都不是创新。候选创新仅是：

> 把失败表示为可检查的适用边界，并用反例和误拦截证据使负记忆自动降权或失效。

## 5. 三创新点导航

本框架用一个统一问题连接三个创新点：怎样复用失败知识减少重复试错，同时避免负记忆错误禁止本来有效的动作。

| 层级 | 创新点 | 主要验证文件 | 关键判据 |
|---|---|---|---|
| 核心创新 | 带适用边界的编译优化负证据表示 | 主线研究框架、完整实验框架 | 是否优于成功案例 RAG 和无条件失败记忆 |
| 支撑创新一 | 适用条件与反例条件驱动的三态门控 | 文献依据、预实验 Demo | 是否降低误拦截并让不确定候选进入补测 |
| 支撑创新二 | 误拦截审计与反例驱动的记忆失效更新 | 完整实验框架、数据记录模板 | 是否恢复有效动作并缩短错误记忆存活时间 |

推荐阅读顺序：先看失败卡片如何表达条件，再看三态门控如何使用条件，最后看误拦截审计如何推翻错误记忆。本方向仍定位为独立备选或第二阶段扩展。

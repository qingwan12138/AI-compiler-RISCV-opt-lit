# FAME-Opt 阶段计划与里程碑

> 以下按依赖关系组织，不是硬性工期。

## M0 环境与基线

### 任务

- 固定 LLVM；
- 2 个程序；
- 参考输出；
- `-O3`；
- 重复计时；
- 环境记录。

### 交付

- 可复现脚本；
- `baseline.jsonl`；
- 噪声报告。

### 通过

同一二进制重复结果稳定，基线前后无明显漂移。

---

## M1 自动性能闭环

### 任务

- 动作执行；
- 编译错误；
- 正确性门控；
- 候选运行；
- 数据库；
- 报告。

### 交付

单命令完成候选编译、验证和计时。

---

## M2 受限 LLM 优化

### 任务

- JSON Schema；
- 提示词；
- LLM；
- 有限候选；
- 反馈轮次；
- 随机基线。

### 交付

- 合法率；
- 编译成功率；
- 正确率；
- 初步性能。

### 决策

若不优于随机，先检查摘要和动作空间，不直接进 RL。

---

## M3 FOEU

### 任务

- Schema；
- 四态；
- 机制冲突样本；
- 正负经验；
- 简单检索。

### 交付

- 20–50 条 FOEU；
- 四态案例；
- 错误解释隔离；
- 未见程序小实验。

### 决策

若与普通日志无差异：

- 加强否定条件；
- 增加跨层证据；
- 增加挑战集；
- 或转可信度评测路线。

## 三条可发表路径

### A 系统与性能

```text
FOEU + 反事实 + 双证书
+ 单平台性能
+ 未见程序
+ RISC-V
```

### B 可信度

若加速有限：

```text
偶然成功挑战集
+ 机制证据
+ 反事实
+ 经验审计
```

### C 测量效率

若优势主要在预算：

```text
主动探针
+ 成本—信息权衡
+ best-so-far
+ 单位预算确认经验
```

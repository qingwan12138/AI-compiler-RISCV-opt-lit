## 5. 动作模板

LLM 只选择动作 ID，执行器映射到安全参数。

```python
ACTION_MAP = {
    "enable_loop_vectorization": ["-fvectorize"],
    "disable_loop_vectorization": ["-fno-vectorize"],
    "enable_slp": ["-fslp-vectorize"],
    "disable_slp": ["-fno-slp-vectorize"],
}
```

展开、分布等可通过：

- 编译参数；
- `#pragma clang loop` 模板；
- 预定义源码变体；
- 受限 Pass pipeline。

不同方法必须共享执行器。

## 6. Remark

```bash
clang -O3   -Rpass=.*   -Rpass-missed=.*   -Rpass-analysis=.*   source.c -o program
```

可加：

```bash
-fsave-optimization-record
```

需要转换成简化摘要再给 LLM，避免直接塞全部日志。

## 7. IR 和汇编摘要

LLVM IR：

- 指令总数；
- load/store；
- call；
- br；
- phi；
- vector type；
- 基本块；
- 循环。

汇编：

- 向量指令；
- 标量浮点；
- branch；
- call；
- load/store；
- 代码尺寸。

首版不需要 GNN。

## 8. 测量隔离

- 固定 CPU 核；
- 关闭后台任务；
- 记录 governor；
- 候选顺序随机化；
- 基线前后复测；
- 超短 kernel 内部重复；
- 正式计时不包含不必要 I/O。

## 11. 单元测试

至少检查：

1. 非法动作拒绝；
2. 编译错误记录；
3. 错误输出不计性能；
4. 浮点容差；
5. 超时；
6. 随机种子；
7. 统计正确；
8. FOEU 分类；
9. 反事实计入预算；
10. `-O3` 回退。

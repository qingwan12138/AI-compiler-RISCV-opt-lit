# AI Compiler Literature Corpus

The canonical literature taxonomy uses the final role of the language model in
the compiler system:

- **LLM as Selector** — selects passes, schedules, configurations, policies, or tool actions.
- **LLM as Translator** — directly emits transformed source, IR, assembly, kernels, or repaired code.
- **LLM as Generator** — emits reusable compiler passes, rules, components, tools, tests, or fuzzers.
- **Supporting Literature** — benchmarks, infrastructure, foundations, traditional ML compiler work, platform background, and methodology.

Agent/RL methods, verification mechanisms, and target platforms are tags, not
top-level categories. See [the taxonomy v2 index](00_三大类分类索引_v2.md),
[classification rules](taxonomy_v2_rules.md), and the [legacy v1 index](archive/taxonomy_v1/00_分类索引_v1_legacy.md).

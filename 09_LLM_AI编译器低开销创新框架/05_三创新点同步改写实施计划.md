# 09 三创新点同步改写实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将三套 LLM AI 编译器实验框架分别改写为“一个核心创新 + 两个支撑创新”，并让九项创新各自具备证据边界、实现机制、独立消融、专属指标、预实验步骤和证伪条件。

**Architecture:** 每套框架保持一个统一研究问题，核心创新改变主要决策机制，支撑创新一提供可验证信息或约束，支撑创新二形成修复、停止或失效更新闭环。先改写根目录的统一口径，再依次同步三个子框架的六份材料，最后进行跨文件一致性验收。

**Tech Stack:** Markdown、PowerShell、ripgrep、Git；研究工具语境为固定 LLM、Clang/LLVM、差分测试和静态指标采集，本轮不新增实验代码或外部依赖。

## Global Constraints

- 每套框架必须采用“一个核心创新 + 两个支撑创新”，三个创新共同回答一个研究问题。
- 九个创新点均包含研究空白、新机制、本质变化、专属消融、专属指标和证伪条件。
- 不把使用 LLM、Agent、RAG、JSON、LLVM、RISC-V 或增加实验指标本身称为创新。
- 信息价值门控保持唯一推荐主线；结构化编辑保持保底/执行器定位；失败边界记忆保持独立备选/扩展定位。
- RISC-V 仅作为后续小规模交叉编译或性能复核平台，不作为框架中心。
- 第一阶段不训练大模型、不扩展为多智能体、不运行大规模真实硬件搜索。
- 所有 Codex 提交信息必须以 `由Codex提交：` 开头。
- 只修改和暂存 `09_LLM_AI编译器低开销创新框架`，不纳入仓库中其他未跟踪文件。

## 8. 三创新点扩展记录

### 8.1 卡片、门控和审计字段

| 字段 | 含义 | 对应创新 |
|---|---|---|
| card_id | 失败卡片编号 | 核心创新 |
| applicability | 适用条件集合 | 核心创新、支撑创新一 |
| falsifier | 能推翻失败结论的反例条件 | 核心创新、支撑创新一 |
| toolchain_scope | 编译器和目标范围 | 核心创新 |
| decision | ALLOW、WARN_AND_MEASURE 或 BLOCK | 支撑创新一 |
| decision_reason | 适用、反例和置信度检查结果 | 支撑创新一 |
| audit | 是否进入反事实审计 | 支撑创新二 |
| audit_sampling_probability | 预先设定的审计抽样概率 | 支撑创新二 |
| actual_result | 被审计动作的编译、测试和收益结果 | 支撑创新二 |
| false_block | 被拦截动作是否实际有效 | 支撑创新二 |
| confidence_before | 更新前置信度 | 支撑创新二 |
| confidence_after | 更新后置信度 | 支撑创新二 |
| status_before | 更新前 active、restricted 或 invalid | 支撑创新二 |
| status_after | 更新后状态 | 支撑创新二 |
| audit_cost | 审计的 Token、工具调用和墙钟成本 | 支撑创新二 |

### 8.2 专属指标复算

- 重复失败率 = 与已有卡片同类且再次失败的动作数 / 全部已知失败动作数；
- FalseBlockRate = 被 BLOCK 但反事实执行有效的动作数 / 被审计 BLOCK 动作数；
- 补测收益率 = WARN_AND_MEASURE 后找到有效动作的任务数 / 全部 WARN 任务数；
- 误拦截恢复率 = false_block 后卡片被缩小或失效并恢复动作的数量 / 全部 false_block 数量；
- 错误记忆存活时间由首次 false_block 到 status_after 为 invalid 或 restricted 的轮数计算；
- 审计净收益必须扣除 audit_cost，不能只报告恢复数量。

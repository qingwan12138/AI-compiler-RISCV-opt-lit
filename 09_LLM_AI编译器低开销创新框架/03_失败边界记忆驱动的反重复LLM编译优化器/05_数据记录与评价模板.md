## 7. 完成检查

- [ ] 失败类型没有混合统计；
- [ ] 卡片每个适用条件均有工具或程序证据；
- [ ] 被 BLOCK 的动作按预注册比例抽查；
- [ ] FalseBlockRate 单独报告；
- [ ] 同家族与未见家族分开报告；
- [ ] 成功案例 RAG 和无条件黑名单完整运行；
- [ ] 反例能触发降权或失效；
- [ ] 记忆长度和 Token 成本纳入公平比较；
- [ ] 编译/测试失败没有计为性能收益。

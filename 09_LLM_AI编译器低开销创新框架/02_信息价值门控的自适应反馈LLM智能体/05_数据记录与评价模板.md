## 6. 关键错误分析

| 类型 | 定义 | 数量 | 代表任务 | 修正方向 |
|---|---|---:|---|---|
| 高价值误判 | 预测高价值但决策未变 | | | |
| 低价值漏判 | 预测低价值但反馈产生有效变化 | | | |
| 有变化无收益 | 决策改变但候选无效 | | | |
| 无变化有收益 | 动作表面相同但参数改进 | | | |
| 过早停止 | 停止后离线存在正价值反馈 | | | |
| 过晚停止 | 多轮反馈未改变决策 | | | |

## 7. 完成检查

- [ ] 所有策略使用相同反馈生成器；
- [ ] 所有预算分别记录，未只报告加权成本；
- [ ] 决策变化定义在实验前固定；
- [ ] StageRule 作为强基线完整运行；

- [ ] 报告校准而非只报告分类准确率；
- [ ] 未见程序家族结果单独报告。

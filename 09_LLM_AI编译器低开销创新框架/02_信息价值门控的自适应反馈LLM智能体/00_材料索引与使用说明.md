# 信息价值门控的自适应反馈 LLM 智能体：材料索引

## 1. 框架定位

本方向研究在固定 Token、工具调用和墙钟预算下，如何只获取真正可能改变优化决策的编译器反馈，并在信息价值不足时主动停止。

定位：**09 中唯一推荐的论文主线。**

## 2. 文件说明

| 文件 | 用途 |
|---|---|
| `01_主线研究框架.md` | 反馈状态、价值函数、决策闭环、研究问题和假设 |
| `02_文献依据与创新边界.md` | 反馈、多 Agent、工具路由和预算分配的近邻碰撞 |
| `03_完整实验框架.md` | 等预算基线、变量、消融、统计和可证伪条件 |
| `04_预实验Demo.md` | 20 个函数、四类反馈、五种策略的低成本 Demo |
| `05_数据记录与评价模板.md` | 每轮反馈选择、预计价值、真实决策变化和成本记录 |

## 3. 最小研究主张

> 在同一个 LLM 编译优化器上，以反事实决策变化概率和反馈成本联合选择下一条反馈，能否比全量反馈和固定阶段规则在相同预算下获得更多有效优化？

## 4. 第一阶段成功标准

- `Valid Improvement@Budget` 高于固定阶段规则；
- Token 和工具调用明显下降，但有效优化质量不下降；
- 预测的决策变化概率与实际变化具有正相关；
- 去掉成本项或主动停止后效果变差；
- 结果不由单个程序或单个错误类别主导。

## 5. 关键警告

2026 年已有工作研究多抽象层预算分配、结构化 compiler remark 和生成期反馈。本方向不能声称首次做预算控制、工具路由或结构化反馈，只能研究**单位成本的反事实决策变化价值**。

## 6. 三创新点导航

本框架用一个统一问题连接三个创新点：怎样知道哪条反馈值得获取、怎样获得可校准的价值标签，以及怎样在多种成本约束下及时停止。

| 层级 | 创新点 | 主要验证文件 | 关键判据 |
|---|---|---|---|
| 核心创新 | 反事实决策变化驱动的反馈价值模型 | 主线研究框架、完整实验框架 | 是否优于固定阶段规则和去项消融 |
| 支撑创新一 | 无需训练大模型的反事实反馈标注与校准 | 文献依据、预实验 Demo | 标签能否预测真实决策变化和有益变化 |
| 支撑创新二 | 多维预算约束的反馈选择与主动停止 | 完整实验框架、数据记录模板 | 是否改善质量—成本曲线而非只节省 Token |

推荐阅读顺序：先理解核心价值函数，再看标签如何产生和校准，最后看在线反馈选择与停止。本框架保持唯一推荐论文主线。

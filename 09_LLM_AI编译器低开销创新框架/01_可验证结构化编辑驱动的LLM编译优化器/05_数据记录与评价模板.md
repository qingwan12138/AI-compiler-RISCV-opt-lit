## 8. 三创新点扩展记录

### 8.1 逐候选字段

| 字段 | 含义 | 对应创新 |
|---|---|---|
| contract_id | 编辑契约编号 | 核心创新 |
| target_region | 允许修改的位置 | 核心创新 |
| action_type | 参数化动作类型 | 核心创新 |
| precondition_declared | 契约声明的前提 | 支撑创新一 |
| precondition_result | 前提检查结果 | 支撑创新一 |
| expected_evidence | 声明的预期证据 | 支撑创新一 |
| expected_evidence_result | 执行后证据检查结果 | 支撑创新一 |
| failure_scope | 被归责的契约字段 | 支撑创新二 |
| repair_fields | 实际允许修复的字段集合 | 支撑创新二 |
| unrelated_changed_lines | 契约范围外修改行数 | 核心创新、支撑创新二 |
| repair_token | 修复阶段输入输出 Token | 支撑创新二 |
| repair_round | 修复轮数 | 支撑创新二 |
| error_recurred | 同类错误是否复发 | 支撑创新二 |
| compile | 是否编译成功 | 统一门控 |
| test | 是否通过测试 | 统一门控 |
| static_gain | 静态指标是否改善 | 统一收益 |
| valid | 是否同时满足编译、测试和收益 | 统一主指标 |

### 8.2 专属指标复算

- 契约执行成功率 = 可被执行器完成的契约数 / 全部契约数；
- 不适用动作率 = 前提检查拒绝数 / 全部动作数；
- 预期效应命中率 = 观察到声明效应的候选数 / 已执行候选数；
- 无关修改率 = unrelated_changed_lines 大于零的候选数 / 全部候选数；
- 错误复发率 = error_recurred 为真的修复轨迹数 / 全部修复轨迹数；
- 首次有效优化轮数由同一任务按 repair_round 和候选轮次排序得到。

### 8.3 分创新完成检查

- [ ] 核心创新的普通 JSON 对照使用相同动作空间和输出长度上限；
- [ ] 支撑创新一分别记录前提检查与预期证据检查；
- [ ] 支撑创新二保留完整重生成和无归责局部修复对照；
- [ ] 所有字段可追溯到原始响应、工具输出和程序差异；
- [ ] 可从原始记录复算三项创新的全部专属指标。

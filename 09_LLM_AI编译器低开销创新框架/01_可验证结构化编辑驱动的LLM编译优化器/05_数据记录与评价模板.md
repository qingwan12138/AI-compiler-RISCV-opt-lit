# 可验证结构化编辑框架：数据记录与评价模板

## 1. 实验批次信息

| 字段 | 记录值 |
|---|---|
| `experiment_id` | `structured-edit-YYYYMMDD-runNN` |
| Git commit | 完整哈希 |
| LLVM/Clang 版本 | `clang --version` 输出 |
| 操作系统 | 版本和内核 |
| LLM/模型版本 | 精确模型 ID |
| 解码参数 | temperature、top_p、seed |
| Prompt 版本 | 文件哈希或版本号 |
| 候选预算 | 每任务候选数、轮数、Token |

## 7. 完成检查

- [ ] 所有方法使用同一任务和模型；
- [ ] Token 与候选预算可比较；
- [ ] 编译失败候选没有进入性能统计；
- [ ] 测试失败候选没有计为加速；
- [ ] 静态收益与运行复核分开报告；
- [ ] 原始 LLM 响应、编辑契约和工具输出均可追溯；
- [ ] 消融结果足以判断核心字段是否必要。

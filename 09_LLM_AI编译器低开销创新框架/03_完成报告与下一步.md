# 09 低开销 LLM AI 编译器框架完成报告与下一步

## 1. 交付结论

已按确认规格生成三套独立的低开销 LLM AI 编译器研究框架。每套框架均包含研究主线、文献边界、完整实验、预实验 Demo 和记录模板。

唯一推荐主线为：

> **反事实决策变化驱动的信息价值反馈门控 LLM 编译优化智能体。**

## 2. 文献证据使用情况

- 本地类别二证据基数：2024—2026 年独立总结 55 份，另有旧边界条目；
- 本轮直接复核：12 份与结构化编辑、反馈选择、优化搜索和失败记忆最相关的总结；
- 综合依据：`08_六类论文创新点提炼/02_LLM编译优化智能体与反馈驱动_候选创新分析.md`；
- 在线碰撞补检：Agentic Code Optimization、Generative Compilation、AI Coding Agents Need Better Compiler Remarks、HintPilot、SemOpt；
- 限制：本轮不是完整系统综述，所有新机制仍标为候选创新。

根目录材料 5 份：

## 4. 三框架最终定位

| 框架 | 最终定位 | 核心指标 | 第一轮预计时间 |
|---|---|---|---:|
| 可验证结构化编辑 | 保底方向/安全执行器 | 编译率、测试率、有效优化率 | 1—3 天 |
| 信息价值反馈门控 | 唯一推荐主线 | Valid Improvement@Budget、首次有效优化成本 | 4—6 天 |
| 失败边界记忆 | 独立备选/第二阶段扩展 | 重复失败率、FalseBlockRate | 4—5 天 |

## 5. 证据强弱

- 证据最充分：编译反馈有效，但多轮反馈存在边际收益递减；成本与反馈内容需要同时评价。
- 证据最薄弱：负证据能否跨程序迁移且不误拦截，目前需要专门实验。
- 碰撞最严重：结构化输出、Hint、优化意图、在线编译反馈和多 Agent。
- 最值得检验：反事实决策变化能否预测哪条反馈真正提高固定预算下的有效优化率。

## 6. 建议保留与暂缓内容

保留：

- 正确性硬门控；
- 局部结构化编辑执行器；
- 等 Token、等工具调用和等候选预算；
- 固定阶段规则强基线；
- 决策变化标注；
- 少量 Top-1 运行时间复核。

暂缓：

- 大模型微调；
- GRPO/PPO；
- 多 Agent；
- 多平台长时间测量；
- 真实 RISC-V 大规模搜索；
- 完整 LLVM 后端修改；
- 将三个框架一次性组合成一个大系统。

## 7. 推荐立即开展的预实验

先执行信息价值门控目录中的 `04_预实验Demo.md`：

1. 准备 20 个有测试的 C 函数；
2. 固定一个 LLM 和三轮预算；
3. 对 40 个代表状态构造四类反事实反馈；
4. 记录反馈前后动作是否实质变化；
5. 比较全量、随机、阶段规则、VOI 和无停止 VOI；
6. 若 VOI 不优于阶段规则，停止扩大该方向；
7. 若 VOI 有优势，再扩展到 60—120 个函数。

# 文献创新证据层设计

## 目标

在现有 taxonomy v2（三大类：Selector、Translator、Generator，及 Supporting）之上，新增只面向文献证据的创新提炼层。它用于识别现有工作已经解决的范围、经论文支持的局限及值得继续核验的机会；不产出研究方案、预实验或最终选题。

## 范围与边界

- 保持 `taxonomy_v2.csv`、三大类索引、PDF、逐篇阅读笔记和所有既有研究方案目录不变。
- 以 169 篇 taxonomy 记录为全量入口；详细证据优先覆盖约 25–35 篇高价值论文。
- Supporting 文献仅在其作为基础设施、基线、评测或方法依据时进入证据层。
- 文献事实、跨文献推导和待核验机会必须明确区分；不得把机会表述为已成立的创新或研究结论。

## 新增文件

### `05_创新证据矩阵.md`

以论文为行、以可比较维度为列。每条记录包含：

- Paper ID 与三大类分类；
- 已解决的问题与最终输出对象；
- 使用的反馈、验证和性能指标；
- 对比基线、是否有真实运行时间测量、可复现材料；
- 论文明确提出的局限及其证据位置；
- 证据强度（强：直接实验或明确对比；中：正文明确陈述；弱：摘要或有限案例）。

它回答“该论文实际证明了什么，以及没有证明什么”。

### `06_局限与反例证据表.md`

以问题为中心汇总 `05` 中的证据。每个问题条目包含：

- 局限的精确定义和适用条件；
- 支持、反例、部分解决三类证据；
- 对应论文及证据位置；
- 事实/推导属性与强度；
- 已有解决路线及尚未验证的部分。

它不把单篇论文的 Future Work 升格为领域共识。

### `07_创新机会观察区.md`

只纳入满足下列任一条件的机会：

1. 至少两篇独立论文给出一致的直接或中等强度证据；或
2. 一篇高质量论文给出系统性实验/专门评测；或
3. 有清晰的反例与可进一步核验的缺口。

每项固定记录“已有工作边界、未解决机制、近邻工作、证据清单、证据不足处、待检索关键词、状态”。状态仅允许：`观察`、`证据补充中`、`待人工判断`，不出现“主创新”“研究方案”等表述。

## 数据流与维护规则

```text
taxonomy_v2.csv + 逐篇阅读笔记
            ↓
05_创新证据矩阵.md（论文级事实）
            ↓
06_局限与反例证据表.md（问题级证据汇总）
            ↓
07_创新机会观察区.md（待核验机会）
```

- 一个普通新增论文只需更新 taxonomy 和（若有可用证据）`05`。
- 只有它强化/反驳某个已有局限时，才更新 `06`。
- 只有达到机会收录阈值时，才更新 `07`。
- 每条机会必须反向链接到 `05` 和 `06` 的具体证据，避免空泛总结。

## 验收标准

1. 新增三个文件，不修改现有文献分类、PDF、笔记和研究方案。
2. `05` 至少覆盖 25 篇高价值论文，并标明筛选范围和未覆盖原因。
3. `06` 的每一项均有 Paper ID 和证据类型；区分论文事实与合理推导。
4. `07` 的每一项均满足收录阈值，并列出证据不足与待检索关键词。
5. 三个文件的 Paper ID 均存在于 `taxonomy_v2.csv`，内部链接有效。

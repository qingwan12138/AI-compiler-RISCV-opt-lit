# 文献语料库仓库整理设计

## 1. 目标

将仓库整理为“文献语料库为主、研究框架集中管理”的结构，同时满足：

- 169 篇正式索引记录不丢失；
- 正式 PDF、逐篇阅读笔记和当前三大类目录不移动；
- 每个研究框架独立占一个目录，其设计、证据、实验和历史版本归入自身目录；
- taxonomy 当前入口与历史迁移材料分离；
- 本地临时产物归档但不提交 GitHub；
- 所有受移动影响的相对链接得到修复和验证。

## 2. 不在本次范围内

- 不删除论文、阅读笔记或研究框架；
- 不重新评价或改写研究内容；
- 不改变 169 篇论文的 Selector、Translator、Generator、Supporting 分类；
- 不重新命名 PDF 论文目录；
- 不运行付费模型或编译实验；
- 不将 Poppler、渲染图片、重复 PDF 和子代理中间文本提交到 Git。

## 6. 非框架说明文件

- `README.txt` 改为根目录 `README.md`，内容改造成仓库导航；
- `文献阅读要求.md` 移入 `docs/文献维护/文献阅读要求.md`；
- 当前 `scripts/`、`tests/`、`skills/` 和 `docs/superpowers/` 保持标准工具目录形态，不并入研究框架。

## 7. 每个框架的内部要求

每个框架顶层至少提供一个 `README.md`。README 只负责导航，不重写研究结论，至少包含：

- 框架名称和当前状态；
- 一句话研究问题；
- 材料阅读顺序；
- 文献依据位置；
- 方法设计位置；
- 实验或预实验位置；
- 历史版本位置；
- 与其他框架的关系仅通过链接说明，不复制其他框架材料。

已有结构清晰的 README 可以复用并修复路径。没有 README 的框架新增简短导航文件。

## 8. `tmp/` 处理

`tmp/` 当前被 `.gitignore` 忽略，内容包括：

- Poppler 可执行文件和压缩包；
- PDF 页面渲染图、重复 PDF 和文本抽取结果；
- 子代理产生的中间阅读文本；
- 一次性 taxonomy 迁移脚本与链接基线。

处理规则：

1. 一次性 taxonomy 迁移脚本和链接基线移入 `archive/taxonomy_v2_迁移过程/工具与证据/`，作为可审计历史材料；
2. Poppler、渲染结果、重复 PDF、抽取文本和子代理临时输出整体移入 `archive/.local/tmp_2026-09-12/`；
3. `.gitignore` 增加 `archive/.local/`，该本地归档不提交 GitHub；
4. 本次不删除本地临时材料。

## 9. 链接更新

目录迁移后仅机械更新受影响的相对链接：

- 根 README 和索引到 taxonomy 规则及历史报告的链接；
- 框架内部导航链接；
- `docs/superpowers/` 中仍需可执行的当前路径；
- 研究框架之间的显式交叉链接。

历史设计文档中用于描述当时状态的路径可以保留原文，但必须明确属于历史记录；不能为了让旧命令看似可运行而篡改历史结果。

## 10. 安全迁移方式

- 已被 Git 跟踪的文件使用 `git mv`，使改动可由 Git 恢复；
- 移动前生成路径映射清单；
- 移动前后分别记录正式 PDF 和逐篇笔记的路径、数量与 SHA-256；
- 不使用批量删除命令；
- 不覆盖同名目标；发现冲突时停止该项并记录；
- 不把当前工作区之外的文件纳入迁移。

## 11. 验证标准

整理完成必须同时满足：

1. `taxonomy_v2.csv` 仍有 169 个唯一 Paper ID；
2. `00_三大类分类索引_v2.md` 仍有 169 条文献记录；
3. 四个正式文献目录的 PDF 数量和 SHA-256 集合与迁移前一致；
4. `文献逐篇阅读/` 的笔记数量和 SHA-256 集合与迁移前一致；
5. 正式索引中的本地 PDF 和笔记链接全部存在；
6. 每个研究框架仅有一个顶层目录；
7. 根目录不残留散落的框架文件或 taxonomy 过程报告；
8. `archive/.local/` 未被 Git 跟踪；
9. `git diff --check` 无格式错误；
10. 仓库现有 taxonomy、文献语料库和创新证据验证脚本全部通过；
11. Git 提交只包含本次目录整理、导航和链接修复。

## 12. 交付方式

整理工作使用独立提交，提交信息以 `由Codex提交：` 开头。实际迁移完成并验证后，再推送到 `origin/main`。最终报告只列出：

- 新目录入口；
- 移动的框架数量；
- 归档的过程文件和本地临时材料；
- PDF、笔记和索引验证结果；
- 未解决的路径或内容冲突；
- commit 哈希和远端同步状态。

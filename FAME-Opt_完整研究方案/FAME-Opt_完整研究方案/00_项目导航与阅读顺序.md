# FAME-Opt 完整研究方案：项目导航

> **项目名称：** FAME-Opt  
> **英文全称：** Falsifiable Attribution Memory for Evidence-guided Compiler Optimization  
> **中文名称：** 基于可证伪归因记忆的 LLM 编译性能优化框架  
> **方向：** AI + 编译器 + 真实性能优化  
> **首版范围：** 单平台、受限动作空间、现成 LLM、不从零训练模型  
> **后续平台：** RISC-V 作为重要实验平台之一，但不作为第一阶段启动门槛

## 2. 三个核心创新点

### 创新点一：可证伪优化经验单元 FOEU  
**重点候选独属创新。**

将一次优化记录为：

```text
适用前提
+ 优化动作
+ 预期机制
+ 应出现的编译证据
+ 能推翻解释的否定条件
+ 正确性结果
+ 性能置信区间
+ 最小反事实结果
+ 适用范围
+ 最终经验状态
```

### 创新点二：信息价值驱动的最小反事实信用探针

不对全部候选做完整消融，只对准备入库、高收益、机制冲突或高复用价值候选回滚一个关键动作。

### 创新点三：语义—盈利双证书门控

分别判断：

1. 优化是否保持语义；
2. 优化在当前程序、输入、编译器和硬件条件下是否具有可靠收益。

正确但变慢的候选不进入可部署正经验库。

## 3. 第一阶段只做什么

- 一台 x86-64 真实机器；
- 5–8 个 C/C++ kernel；
- `-O3` 基线；
- 8–12 个固定宏动作；
- 每程序 6–8 个候选；
- 编译、差分测试、重复计时；
- Optimization Remarks 和简化汇编证据；
- 每程序最优候选最多 1–2 次反事实；
- 至少构建一个完整 FOEU。

第一阶段不修改 LLVM 后端、不做三平台、不做完整 Pass 搜索、不从零训练 LLM、不要求所有候选 Alive2 验证。

---

## 4. 研究继续条件

满足以下大部分条件后再扩展：

1. 流程可以自动运行和复现；
2. 部分保留测试程序相对 `-O3` 有稳定提升；
3. 相同候选预算下优于随机搜索或无反馈 LLM；
4. FOEU 能区分确认成功、偶然成功和机制无收益；
5. 选择性反事实比全量反事实节省测量；
6. 双证书降低负优化或改善最差程序表现；
7. 核心收益不是来自更多候选或更多 LLM 调用。
